# Smart Campus Navigator

A web-based campus navigation system developed using **Java Spring Boot** and **Dijkstra's Algorithm** to find the shortest path between different locations on a college campus.

## 🚀 Features

* Find the shortest route between campus locations
* Interactive campus map interface
* Fast route calculation using Dijkstra's Algorithm
* REST API-based architecture
* Responsive frontend using HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* Java 21
* Spring Boot
* Maven
* HTML
* CSS
* JavaScript
* Docker
* Git & GitHub
* Render (Deployment)

## 🧠 Algorithm Used

This project uses **Dijkstra's Algorithm** to calculate the shortest path between a selected source and destination node within the campus map graph.

## ▶️ Running Locally

1. Clone the repository

```bash
git clone https://github.com/Krishna-Dhamanekar/Campus-Navigator-System.git
```

2. Navigate to the project folder

```bash
cd Campus-Navigator-System
```

3. Run the application

```bash
./mvnw spring-boot:run
```

4. Open in browser

```text
http://localhost:8080
```
