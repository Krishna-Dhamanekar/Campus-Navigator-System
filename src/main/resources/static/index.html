Campus Navigator
Shortest Path Navigation Using Dijkstra's Algorithm
A Spring Boot-based web application that finds the optimal route between campus locations using Dijkstra's Algorithm. The campus is modeled as a graph where locations are nodes and pathways are edges with distance, travel time, and traffic attributes.
Click any node on the map to set your starting point
Cost Metric Config: W = 1.0×Dist + 0.5×Time + 2.0×Traffic
